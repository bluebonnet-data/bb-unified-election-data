The short version

From ten counties to the whole state

236 of 254 Texas counties now have U.S. House results (2016 to 2024) translated onto the 2026 congressional map. All of it is committed to the repo, and every one cleared a vote leakage check.

Early on, we had ten counties, done by hand. The work since has been about getting from ten to the whole state, and finding out what breaks along the way.

What we built

The machinery

A batch runner

A single command runs the full pipeline for any county: load its precincts, build the weights table against the 2026 districts, interpolate the votes, and check the result. The same command scales to the whole state: point it at all 254 counties and it works through each one, flagging any that need a closer look.

A precinct ID reconciler

This was the real unlock, and it is worth explaining.

Election results and precinct boundaries come from different sources, and they disagree about what a precinct is called. One county's results say 0050001 where its map says 50001. Another says 190007 where the map says 370007. Some IDs carry suffixes the map has never heard of. When an ID does not match, that precinct's votes have nowhere to land. They vanish. That is vote leakage, and at first it was affecting 47 counties.

The reconciler tries the ID as written, then a handful of known variants, and keeps whichever one actually matches a real precinct on the map. It never forces a match. If nothing fits, the county gets flagged rather than quietly given wrong data.

It took the review pile from 47 counties down to 8.

Leakage checking at scale

Every county, every cycle, we check for vote leakage: does the interpolated total still match the votes we started with? Nothing gets saved unless a county clears that check. Counties that fail still run, so we can see why, but they write nothing.

What we learned

Three things we learned

The real problem was precinct IDs

It looked like it might be 254 separate problems. It turned out to be a handful of patterns repeated across counties, so once we recognized a given pattern, the reconciler could handle each county that shared it.

Handling uncontested races

When only one party fields a candidate, there is no two-party split to measure. Showing a number anyway would be misleading, so we mark those cycles instead.

A county is not a district

Each county file holds that county's contribution to the districts that overlap it. Tarrant County touches seven districts, and some of them barely touch Tarrant. This is correct, but it is easy to misread, and it points to a bigger question.

The honest question

Districts are a solid starting point

District level works. We can now put every cycle from 2016 to 2024 on the same map and see how a place moved. That was the goal, and the data is there.

But a district is a big place. Knowing that one of Tarrant County's seven districts shifted a few points does not tell an organizer where to go on a Saturday. The question people actually have is about neighborhoods, and a district is too coarse a unit to answer it.

District level works.
But is it granular enough?

Precinct level is where the neighborhood view lives, and the method is identical: same interpolation, same leakage check, with a fixed precinct map as the target instead of a district map. The hard part is scale: orders of magnitude more target shapes, across the whole state.

The next step is to pilot it on a county or two and find out whether it delivers what we want, before committing to the whole state.
